## File Naming Convention

The files are named in the format:

`U1P1`

Where:

* **U** = Unit
* **P** = Program
* **E** = Extras
* **Ex** = Examples

### Multiple Versions

If a program has multiple versions, they are marked using letters such as:

`U1P1A`
`U1P1B`
`U1P1C`
`U1P1D`

This naming convention keeps all practical programs organized and easy to identify.
